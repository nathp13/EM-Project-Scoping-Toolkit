# Project Scoping and Assessment Toolkit
Engineering students often rush into developing solutions before fully understanding the problem they are trying to solve. The Project Scoping and Assessment Toolkit was developed to help students take a more deliberate approach to project-based learning by defining problems, identifying requirements and constraints, and revisiting assumptions throughout a project. The toolkit consists of modular resources that support project scoping, progress reviews, team collaboration and decision-making, feedback integration, and reflection. Entrepreneurial mindset principles are embedded throughout the toolkit by encouraging students to explore problems from multiple perspectives, make connections across disciplines and stakeholders, and evaluate the value proposition of their project. Originally developed for Rowan University's junior and senior Engineering Clinic program, the toolkit is designed to be adaptable to a broad range of project-based learning environments, including design, research, computational, and multidisciplinary projects.

## Instructor Tips
The toolkit is modular. Instructors may implement individual modules or combine multiple modules based on course needs and project complexity.
Start with the Project Scoping module. Even when used on its own, it can help students develop a deeper understanding of the problem before pursuing solutions.

## Learning Objectives
-Define and scope engineering problems by identifying stakeholder needs, project constraints, risks, and success criteria. 
-Evaluate project decisions from multiple perspectives, including technical, social, environmental, and economic considerations. 
-Apply systems thinking to understand how engineering projects interact with broader stakeholders, communities, and contexts. 
-Use evidence, feedback, and reflection to refine project decisions and adapt project plans as new information becomes available. 
-Collaborate effectively in project teams by communicating project goals, responsibilities, and decision-making processes. 
Recognize opportunities to create value through engineering solutions that address stakeholder needs and project objectives.

## Toolkit Components

### Project Scoping
Help students define project goals, stakeholders, constraints, assumptions, and success criteria through structured project scoping modules, including:
- Project Scoping
- Progress Check
- Team Collaboration
- Project Learnings

### Project Assessment
In addition to final project presentations, reports, and project artifacts, the toolkit includes a peer and self-assessment template. This instrument allows students to evaluate individual and team contributions, promote accountability, and support reflection on team performance.

### Project Intervention Timeline
Provides a roadmap for implementing project scoping, progress checks, deliverables, and assessment activities throughout a project.
